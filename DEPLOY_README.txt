MetaOneClick premium homepage package

Upload the CONTENTS of metaoneclick_site/ to your website public_html folder. Back up the existing site first. This package preserves the previous service pages and replaces the homepage.

Original approved logo: assets/metaoneclick-logo.png
Lead form: FormSubmit -> contact@metaoneclick.com. FormSubmit may require email activation/confirmation on first use. Test with a real submission after deploying. No server-side submission has been tested here.

If using GitHub Pages, upload the folder contents to the repository root. If using cPanel, upload contents into public_html.
